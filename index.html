妈妈｜更年期注意事项

  • 暴汗、潮热：穿轻薄分层衣物，晚上保持卧室凉爽；留意咖啡、浓茶、酒、辛辣或很烫的饮品是否会诱发症状。

  • 运动：保持规律快走，并加入力量训练/负重运动，既帮助睡眠，也有利于骨骼健康。

爸妈怎么吃

按爸爸目前高血压、高尿酸、结石史，以及妈妈更年期阶段，整理成“经常吃 / 偶尔吃 / 少量吃”的家庭版。

经常吃
三文鱼：优先中段 / 中腰段 / 菲力
我们家：爸妈都可以吃。优先买去骨菲力、中段或中腰段；鱼腩、中トロ/大トロ这类更肥的部位放到偶尔吃。
份量
每人一餐约80–100g。
说人话
给爸妈长期吃，选不那么肥、好分量、好做熟的部位最省心。蒸、烤、少油煎都可以，少盐、少甜酱。
为什么
爸爸有高血压、高尿酸、结石史，也偶尔暴饮暴食，所以比起高脂鱼腩，更适合中段/中腰段。妈妈更年期阶段可把三文鱼作为日常优质蛋白来源，但它不是更年期治疗食品。
优先熟吃
三文鱼：熟吃比生吃更适合爸妈长期吃
我们家：爸妈日常更推荐熟三文鱼；刺身可以偶尔吃，但选正规冷链、明确可生食的。
说人话
熟食主要是更稳妥，能降低寄生虫和细菌风险。高尿酸这件事，生熟不是决定因素，份量和总饮食结构更重要。
可以买
甜虾：可以买，但爸爸少量、偶尔吃
我们家：妈妈正常吃没特别问题；爸爸有高尿酸和结石史，所以别把甜虾当高频主菜。
份量
爸爸一次大约5–8只左右，别同一顿再叠加很多海鲜、内脏或酒。
说人话
甜虾可以解馋，但日常蛋白更优先三文鱼中段、普通鱼排这类。生食时注意冷链和卫生。
可以买
海胆：可以吃，但爸爸少量
我们家：偶尔吃寿司那种少量没问题，不建议爸爸一顿大量吃海胆。
说人话
爸爸重点还是避免一顿里“很多海鲜 + 高盐 + 含糖饮料/酒”一起叠加。
日常可选
金枪鱼：优先赤身，少选中トロ / 大トロ
我们家：给爸爸日常吃，普通瘦金枪鱼比肥的中腹、大腹更合适。
说人话
大型金枪鱼不建议天天大量吃，和三文鱼、其他鱼类轮换更好。
爸爸重点
不要暴饮暴食
我们家：爸爸有时会暴饮暴食，这条单独列出来。
说人话
尽量别一顿吃特别多，尤其避免“大量肉 + 高盐菜 + 含糖饮料”一起上。聚餐前后也不要靠“饿一顿、下一顿猛吃”补偿。
